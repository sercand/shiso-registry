Model card

Qwen3.5-4B-GLB-3D-Coder

Early preview · Create 3D scenes and assets you can export as GLB

A small 4B coding model being trained to generate Three.js scenes and assets with GLB export, so you can bring the results into editors such as Godot.

This is an independent model by CCORE, based on Qwen/Qwen3.5-4B. It is not an official Qwen release.

Dataset release update: The training dataset will be released tomorrow, November 3. Training is still in progress: I’ve extended the run to aim for a stronger checkpoint than the current preview.

Community showcase: A 3D RPG built with GLB-3D-Coder!

One of the coolest things about releasing this model is seeing what people are building with it!

Naoki Kishida (@kis) created a playable 3D RPG demo using assets generated with GLB-3D-Coder.

It's a great example of what I had in mind when developing this model: generating reusable 3D assets that can be used in games and interactive environments.

Preview status and release plans

This is an updated preview from the ongoing training run. Training is still in progress. Once training finishes, I plan to release the full Safetensors weights and the training dataset, just as I did with the previous 3D Coder release.

In my tests, the model already generates useful scenes and assets, and most generations work on the first attempt, especially with English prompts. Some generations still need another attempt or a correction.

I am releasing this preview so people can start experimenting while training continues. I expect quality to improve with later checkpoints, and feedback on both successful results and failures is welcome.

From a prompt to a GLB asset

Describe the scene or asset you want. The model generates HTML/JavaScript that builds it in Three.js, with a GLB export option. Open the generated scene, export the asset, and import the .glb file into your editor.

Optional vision support

For image-reference inputs in a runtime that supports Qwen3.5 multimodal GGUF, download the optional vision encoder/projector and load it alongside the model:

Download mmproj-Qwen3.5-4B-BF16.gguf — approximately 644 MiB.

The same projector is used with either Q4_K_M or Q8_0. It is an optional companion file for image inputs; it is not needed for text-only prompts.

This is the original, unmodified Qwen3.5-4B BF16 vision encoder/projector, also provided with CCORE's previous 3D Coder model. It comes from lmstudio-community/Qwen3.5-4B-GGUF, based on Qwen/Qwen3.5-4B, under Apache 2.0.

System prompt

Use the following as the system message, then send your asset request as the user message.

Create game assets for the Godot editor, which uses GLB files. Create whatever the user requests as a good-quality low-poly asset using only Three.js in one complete standalone HTML file. The HTML must show the asset and include an Export GLB button that downloads a working GLB. If the requested asset needs animation, add it and include the animation in the exported GLB; otherwise make it static.

Current limitations

  • Some generations can need a retry or a small code correction.
  • English prompts currently work better in my tests.
  • This is an early checkpoint, and behavior may change as training progresses.

Please share what you create, which settings you use, and any issues you find. Community testing will help guide the next updates.
