Model card

From the README on Hugging Face at the pinned revision.

Idol

A single image to a 3D Gaussian splat.
One picture of an object in, up to a million 3D Gaussians out, including the sides the picture never showed.

Idol turns one picture of an object into a 3D Gaussian splat. Give it a render, a generated image or a photo: it removes the background, frames the object and generates up to 1,048,576 Gaussians, written as a standard 3DGS .ply. It runs on consumer GPUs, using 7.2 GB of VRAM and can run in under 2 seconds.

Get started

1. Get access to the image encoders. Idol reads its input through two gated models on Hugging Face. Accept their terms with your Hugging Face account, then log in once with hf auth login (or set HF_TOKEN):

  • facebook/dinov3-vith16plus-pretrain-lvd1689m
  • black-forest-labs/FLUX.2-dev (only its VAE is downloaded)

2. Install the code

git clone https://github.com/speridlabs/idol-sdk.git
cd idol-sdk
pip install -e .          # Python 3.10+, PyTorch 2.5+, an NVIDIA GPU with CUDA

There is no separate download step: on the first run, Idol's weights (about 3 GB, from this repository) and the two image encoders download automatically into the Hugging Face cache. If the encoders are not accessible yet, Idol stops before downloading anything and says what is missing.

3. Generate a 3D object

python -m idol.sample --image photo.jpg --mode real
python -m idol.sample --image renders/ --mode synthetic --out outputs

For each image this writes <name>.ply (open it in any Gaussian splat viewer), <name>_input.png (the image the model saw, after background removal and cropping) and <name>_camera.json (the predicted camera of the input).

Pick the mode for your input. It sets how much room the crop leaves around the object:

--modeforcrop
synthetic (default)renders and generated images of a single objectobject fills 1/1.2 of the frame
realphotographsobject fills 1/1.7 of the frame

From Python:

from idol import IdolPipeline

pipeline = IdolPipeline.from_pretrained("speridlabs/idol")
output = pipeline("photo.jpg", mode="real", seed=42, num_gaussians=1_048_576)
output.gaussian.save_ply("photo.ply")

Flags

FlagDefaultWhat it does
--seed42Fix it to get the same object again.
--steps50Sampling steps. Fewer are faster but lose some detail.
--cfg_strength3.0Classifier-free guidance: how strictly the object follows the image.
--rescale_t3.0Time shift: higher spends more steps on the overall shape, lower on fine detail.
--num_gaussians26214432,768 to 1,048,576, a multiple of 32.
--dinov3_dtypebf16fp32 runs the DINOv3 encoder in full precision (1.7 GB more memory).
--weightssperidlabs/idolA Hugging Face repo or a local folder.
--no_optimizeoptimizedTurn off the faster sampling.

Faster sampling is on by default on GPU (~1.7x, same output quality): the denoiser is compiled with torch.compile, the guided and unguided passes run as one batch, and attention uses cuDNN with TF32 matmuls while sampling. The first image in a process is slower while it compiles.
